# 📊 Sales Dashboard Project

## 📌 Project Overview

This project is a **Sales Dashboard** created to analyze sales performance, product performance, customers, countries, revenue, tax, and profit.

The dataset contains **2,823 sales records** with information about products, customers, locations, sales, quantity, tax, and profit.

## 🛠️ Tools Used

* Microsoft Excel
* Power BI
* SQL / Data Analysis
* GitHub

## 📂 Dataset

The dataset contains the following important columns:

* `QUANTITYORDERED` – Number of products ordered
* `PRICEEACH` – Price of each product
* `SALES` – Total sales amount
* `Year` – Sales year
* `Product` – Product category
* `CUSTOMERNAME` – Customer name
* `CITY` – Customer city
* `COUNTRY` – Customer country
* `FullName` – Customer/contact name
* `Tax` – Tax amount
* `Profit` – Profit generated

## 📊 Dashboard Analysis

The dashboard can be used to analyze:

* Total Sales
* Total Profit
* Total Quantity Ordered
* Sales by Year
* Sales by Product
* Profit by Product
* Sales by Country
* Sales by Customer
* Product performance
* Customer performance

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into meaningful business insights using data visualization and analysis.

The dashboard helps users understand:

1. Overall sales performance
2. Profit generated from sales
3. Product-wise performance
4. Country-wise sales
5. Customer-wise sales
6. Yearly sales trends
7. Quantity ordered and revenue
